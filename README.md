# 极简书签 (Quick Bookmarks) 🔖

> 类似经典 **Popup my Bookmarks (PmB)** 的轻量级 Chrome 书签气泡弹窗扩展。秒开流畅、零白屏、高密度排版，支持级联多列与经典树状双视图、即时拼音搜索、全键盘导航与拖拽排序。

---

## ✨ 核心特性

### ⚡ 极致轻量 & 零延迟响应
- **原生极速引擎**：纯原生 JavaScript + CSS 构建，无任何第三方重型框架，冷启动时间 < 50ms。
- **高密度紧凑排版**：单项默认 22px 紧凑高度，极小边距，单屏展示更多书签。
- **暗色模式无缝适配**：随系统设置自动切换深色/浅色高对比度主题。

### 📂 双视图自由切换
- **级联多列面板 (Cascade View)**：
  - 点击或悬停文件夹向左平滑展开多级子面板。
  - 单列支持独立快速关闭（`✕`），顶层支持置顶“其他书签”。
- **经典树状折叠 (Tree View)**：
  - 支持多层级缩进与折叠，提供一键「展开全部」与「收起全部」。
  - 自动记忆各文件夹的折叠/展开状态。

### 🎯 Menu Aim 斜向防误触算法
- 内置智能鼠标移动轨迹预测与三角安全区判定。
- 从一级菜单向二级子面板斜向移动时，自动提供毫秒级缓冲，**绝不误触中间兄弟菜单**。
- 同列垂直上下浏览时 **80ms 极速响应**，悬停即切，丝滑跟手。

### ⌨️ 全键盘极速导航
- **方向键全功能支持**：
  - `↑` / `↓`：在当前列列表项中快速移动高亮。
  - `←` / `→`：跨列进入子文件夹面板或返回上一级父面板。
  - `Enter`：打开当前选中的书签或展开/收起文件夹。
  - `Home` / `End`：一键跳转至当前列表顶部或底部。
  - `Ctrl + F` / `⌘ + F`：一键聚焦搜索框。
- 鼠标操作与键盘焦点完美解耦，鼠标移出自动清除高亮边框，清爽不留痕。

### 🖱 原生拖拽移动与排序 (Drag & Drop)
- 支持通过鼠标左键按住书签、文件夹或分隔条自由拖拽排序。
- 智能指示线：
  - 拖至项目**上半部**：插入到上方。
  - 拖至项目**下半部**：插入到下方。
  - 拖至文件夹**中间**：直接移入该文件夹内部。
  - 拖至列表**空白处**：追加到该文件夹末尾。
- 拖拽调整实时同步至 Chrome 底层书签树。

### ➖ 全能分割条与分类标题
- 分割条本质为标准书签项，支持随心拖拽排序、右键管理与双击编辑。
- 自动智能识别带文字的分组书签（如 `- - - - - AI工具 - - - - -` 或 `--- 常用 ---`），渲染为居中文字分类细线，去除突兀字符与图标。

### 📋 原生风格右键管理菜单
- **打开方式**：在背景标签页打开 / 在新窗口打开 / 在隐身窗口中打开。
- **节点管理**：修改（双击亦可快速修改）、删除、添加当前网页、新建文件夹、添加分割条。
- **跨目录剪贴板**：剪切、复制（支持递归复制整个目录树）、粘贴（无数据时自动置灰）。
- **智能排序**：支持按拼音自然语言升序排序当前目录。

### ⚙️ 全能设置面板 (Settings)
点击弹窗顶部的 **`⚙ 设置`**，支持实时自定义：
- **尺寸与外观**：自定义单列面板宽度（160px ~ 400px）、弹窗高度（300px ~ 600px）、单项行高（20px / 22px / 25px / 28px）、字体大小。
- **交互偏好**：左键打开方式（当前标签页 / 新建前台标签页 / 新建后台标签页）、悬停延时（极速 0ms / 快速 80ms / 标准 160ms / 仅点击）、是否置顶其他书签、是否美化分类分隔条。
- **快捷键直达**：内置快捷键说明，一键直达 Chrome 扩展快捷键配置页。
- **配置持久化**：支持通过 `chrome.storage.sync` 跨设备同步所有设置。

## 🚀 安装指南

1. **下载或克隆本仓库源码**：
   ```bash
   git clone https://github.com/evanhy/bookmark-sidepanel.git
   ```
2. **在 Chrome 中加载扩展**：
   - 打开 Chrome 浏览器，在地址栏访问：`chrome://extensions/`
   - 打开右上角的 **「开发者模式 (Developer mode)」** 开关。
   - 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」**。
   - 选择本项目的根目录文件夹 `bookmark-sidepanel` 即可安装完成。

---

## ⌨️ 快捷键配置

推荐将弹窗绑定为全局弹出快捷键，享受极致效率：

1. 在 Chrome 地址栏输入并回车：
   ```text
   chrome://extensions/shortcuts
   ```
2. 找到 **极简书签 (Quick Bookmarks)** -> **打开书签弹窗**。
3. 点击编辑框，按下您喜欢的快捷键：
   - **Mac 推荐**：`⌘ + E` / `⌥ + E` / `⌘ + ⇧ + E` / `Control + E`
   - **Windows 推荐**：`Alt + E` / `Ctrl + Shift + E`
